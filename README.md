# baltaqua.eu

BaltAqua – tvenkinių ir žuvininkystės įranga (MB „Baltgate“).
Svetainė: https://baltaqua.eu (GitHub Pages, šaka `main`, šakninis aplankas).

Svetainė yra vienas failas `index.html` (šriftai Bitter ir Golos Text bei Lucide piktogramos įterpti; animacijų bibliotekos GSAP ir Lenis laikomos aplanke `vendor/` ir nėra būtinos – be jų puslapis veikia pilnai).
`404.html` – tos pačios svetainės kopija nežinomiems adresams.
